The AI Loan Approval System (ALAS) is a fictional machine learning system designed to automate loan approval decisions for a mid-sized financial institution. This case study evaluates ALAS using the NIST AI RMF, EU AI Act, and ISO 42001 governance principles to identify risks, harms, controls, and monitoring requirements. 

This assessment concludes that ALAS qualifies as a High-risk AI System under the EU AI Act due to its impact on financial access and socioeconomic outcomes. the system requires strong governance controls, continuous monitoring, and human oversight.
